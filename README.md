# 🛒 Zepto SQL Business Analysis
SQL Business Analysis Project using Zepto Kaggle Dataset

## 📌 Project Overview

This project analyzes the **Zepto Product Dataset** from Kaggle using **MySQL**. The objective is to perform data cleaning, explore product data, and answer real-world business questions that can help understand pricing strategies, inventory management, discounts, and revenue opportunities.

---

## 📂 Dataset

* **Source:** Kaggle – Zepto Product Dataset
* **Database:** MySQL
* **Records:** Product catalog containing pricing, discounts, inventory, and category information.

---

## 🛠 Skills Demonstrated

* SQL (MySQL)
* Database Design
* Data Cleaning
* Aggregate Functions
* CASE Statements
* GROUP BY & HAVING
* ORDER BY
* Data Analysis
* Business Analysis

---

## 📋 Database Operations

* Created MySQL database and table
* Imported CSV dataset
* Identified missing values
* Removed invalid records
* Converted prices from paise to rupees
* Checked duplicate products

---

## 📊 Business Questions Solved

* How many products are available in the dataset?
* Which product categories are available?
* Which products are currently out of stock?
* Which products offer the highest discounts?
* Which premium products are unavailable?
* Which categories generate the highest estimated revenue?
* Which categories provide the highest average discount?
* Which products provide the best value based on price per gram?
* How can products be categorized by weight?
* What is the total inventory weight for each category?

---

## 💡 Key Insights

* Estimated revenue varies significantly across product categories.
* Some premium-priced products are currently out of stock.
* Discount strategies differ by category.
* Price-per-gram analysis helps identify value-for-money products.
* Inventory weight analysis highlights stock distribution across categories.
